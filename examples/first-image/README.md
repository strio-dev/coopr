# First image

Build an OCI container image that prints a greeting generated by a local component. The component's producer stage creates `/hello.txt`, its `package` stage captures the file, and `extend` copies it into the calling image.

From the repository root:

```sh
coopr build --file examples/first-image/image.coopr --tag hello:latest examples/first-image
podman run --rm localhost/hello:latest
```

Expected output:

```text
Hello, world!
```

See the [first-image tutorial](../../docs/tutorials/first-image.md) to create these files yourself and try rebuilding after a change.
